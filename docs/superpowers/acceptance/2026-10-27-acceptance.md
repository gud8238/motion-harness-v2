### 제작 중 발견한 문제 (저장소에서 고침, 단위 테스트 포함)

1. **게이트가 morph.md 의 '눈 → 로고 글자' 예시를 막음** — 예시는 `morph.text(` 로 글자 윤곽만 불러오고 실제 모핑은 `morph.many(` 인데, `morph.text(` 가 morph.text 근거를 요구했다. 감지기는 이 장면을 늘 `morph.shape` 로만 제안하므로(blobContour) B 근거로는 문서대로 쓸 수 없었다 → 카탈로그 morph.shape api 에 `morph.text(` 추가(R14·R19 와 같은 공유 방식), morph.md 게이트 줄 수정.
2. **리그: 첫 위치 동작이 늦은 `enter` 면 그 전까지 배우가 기본 자리(0,0, 화면 왼쪽 위)에 보임** — 무대 템플릿 기본 큐(0.8s enter)부터 해당. 이제 첫 위치 동작이 enter 면 그 전에는 등장 출발 자세(화면 밖, scale 은 배율 0)로 기다린다.
3. **모션 검수가 레퍼런스 강조색만으로 덩어리를 찾음** — 사용자·원작 색 캐릭터(코랄)는 공유 요소·모핑·매치 컷이 영영 ✗. 이제 `scene/index.html` 의 `window.DNA` HEX 중 채도 높은 색(Lab C* ≥ 30)을 더한다(`dnaAccents`).
4. **모션 검수: 짧은 후보는 통과할 수 없었음** — 겹침 0.5초 요구 때문에 0.1~0.2초짜리 채움·매치 컷 후보(레퍼런스 B 의 채움도 0.08~0.17s)는 계획한 자리에 있어도 ✗. 이제 후보가 짧으면 후보 전체가 구간 안에 있으면 통과.
5. **모션 검수: 맞닿은 사용 위치(`st1 b5, s2`)를 따로 비교** — 컷을 걸친 매치 컷 후보가 양쪽에 반씩 걸려 ✗. 맞닿은 구간은 합쳐 비교.
6. **모션 검수: trans.shared 는 컷 2개 미만이면 감지기가 돌지 않는데 ✗ 로 표시** — 원테이크 무대 영상에서는 구조상 늘 ✗. 이제 `?`(눈 확인, "컷 N개 — 감지에 2개↑ 필요").
7. **qc-motion.png '우리 영상' 줄이 늘 사용 위치 처음을 보여 줌** — s2(6.5초) 안 17초의 모핑이 strip 에 안 나옴. 이제 감지된 자리가 있으면 그 가운데를 중심으로 같은 길이를 보여 준다("(감지된 자리)").

### 고치지 않은 것 (참고)
- `lens.rack` 감지는 "가장 선명한 칸"이 2칸↑ 옮겨 가야 하는데, 글자 벽처럼 고르게 선명한 화면에서는 우세 칸이 없어 잡지 못한다(레퍼런스 B 3–4.5s 도 자동 후보 없음, 수동 strip 근거로 사용).
- `morph.shape` 단일 덩어리 비교는 방사 서명이라 둥근 덩어리 → 둥근 알약(가로세로비 2.5) 은 유사도 0.73 으로 모핑이 아니다(3.5:1 은 0.61). 처음 설계(몸 → 로고 판)는 ✗ 였고 몸 → 가는 미소 띠로 바꿔 ✔.
- 화면 전체 비네트 오버레이가 채움 색을 32단계 칸 여러 개로 나눠 fillRatio 가 49% 로 떨어졌다(R5 의 "잡음 있는 채움은 낮게 읽힘"). 장면에서 비네트를 배우 아래로 옮겨 해결 — GUIDE 에 한 줄 넣을 여유가 없어(13 B) 문서화하지 않음.
- `morph.split` 은 첫 부분경로를 바깥 윤곽으로 본다 — 라틴 글자(o·a)는 맞지만 한글처럼 바깥 조각이 여러 개인 글자는 나머지 조각이 '구멍'으로 처리된다(이번엔 라틴 이름으로 피함).
