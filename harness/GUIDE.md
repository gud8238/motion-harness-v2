# motion-harness2 가이드 (이 한 파일이 기준)

레퍼런스 스타일을 **빠짐없이** 옮겨 사용자 이미지·주제로 15~40초 모션그래픽(HyperFrames). 도구 `node "<플러그인>/harness/tools/<도구>.mjs"`(스킬의 전체 경로). `P` = `.`(연 폴더, 바로 아래 `ref/`·`source/`) 또는 하위 폴더.
**3단계**: ① 기본기 항상(강도만 레퍼런스) · ② 스타일 효과는 **레퍼런스 근거 이미지가 있을 때만** · ③ brief "효과 지정"에 적힌 것.

## 1. 품질 우선 원칙
1. **합격선이 먼저다.** 6절 채점표의 합격선(핵심 5개 항목 5점, 나머지 4.5 이상, 기준선이 있으면 항목마다 +1)을 넘을 때까지 만든다. 비용·시간은 그다음 문제다. 문서·참고 이미지·모듈 문서는 품질에 도움이 되면 얼마든지 연다.
2. **움직이는 상태로 본다.** 검토는 정지 스토리보드 한 장이 아니라 장면마다 연속 프레임(`board.mjs P --strip <id> --n 8`)과 초안 영상(`make.mjs P --draft`)으로 한다.
3. **소스는 재료다.** 소스 이미지는 붙이는 완성품이 아니라 형태·색·구조를 뽑아 **움직일 수 있게 다시 만드는 재료**다(2.5절). 사진을 통째로 옮기기·확대·기울이기만 하는 사용은 금지.
4. **글자보다 동작.** 브리프의 모든 동사는 피사체가 직접 그 동작을 하는 장면으로 보인다. 라벨·자막은 보조다(3절 동작 표).
5. **레퍼런스의 장점을 전부 가져온다.** 팔레트·컷만이 아니라 주인공의 연기, 장면을 잇는 방식, 움직임 성격까지(2절 2).
6. **검수 지표를 위해 장식하지 않는다.** 게이트·모션 검수 ✔는 참고값이지 점수가 아니다.
7. 품질에 필요한 코드는 런타임에 아낌없이(`MH.*` 는 토큰 비용 0). 부품 함수·리그를 직접 짜는 데 망설이지 않는다.
8. 질문은 처음 **한 번**(AskUserQuestion, 추천안 먼저), 브리프로 답이 되면 생략. 채점 루프 상한(6절)에 걸리면 다시 묻는다.

## 2. 순서
1. **입력**: `brief.md`, `ref/`, 소스 `assets.mjs sheet P`→`work/sources.png`(크기·배경·종류 추정). 링크·ID `refs.mjs fetch P <ID|링크>`. 레퍼런스 없음·"추천"→`/motion-harness2:mv-refs`.
2. **측정·해독**: `analyze-ref.mjs P ref/<파일>`→`work/ref-<이름>/` `analysis.md`·`card.png`(DNA 근거), `evidence.json`·`evidence.png`(효과 후보 8개씩, `evidence_2.png`…), `sheet.jpg`·`motion_N.png`. 측정값 외에 Claude가 sheet·motion 을 보고 **해독**한다: 매체(손그림/플랫 벡터/실사/3D/혼합) · 주인공과 연기 어휘(걷기·점프·예비 동작·표정·찌그러짐…) · 장면을 잇는 방식(형태 변형·매치컷·줌 통과·채움·하드컷) · 움직임 성격(2s·boil·겹침 동작) · **이 레퍼런스가 좋은 이유 5가지**(전부 시그니처로 배정).
2.2 **근거표 확정**: evidence.png(쪽마다) 후보 확정·기각(신호가 보이고 쓸 것인가)→analysis.md `→ 근거 칸:` 문구(`<이름> <t0>–<t1>s (ev_<id>_<t0>.png)`)를 효과 표에. 놓친 효과: `analyze-ref.mjs strip P ref/<파일> <t0> <t1>`→`ev_mNN.png`·근거 칸. **근거 이미지 없는 ② 금지** — 이미지 레퍼런스는 ② 근거가 없어 ③(brief 효과 지정)만.
2.5 **소스 해부·재구성**(2.5절) — 모든 소스를 종류·움직임 단위·재구성 방식으로 나눈다. 레퍼런스 느낌에 꼭 필요한데 소스·코드로 만들 수 없는 이미지만 요청: ASSETS.md→**⏸** AskUserQuestion `이미지 추가 완료` / `일부만 넣고 진행` / `이미지 없이 진행(코드로 대체)`→`assets.mjs check P` + `new.mjs P`, 새 이미지만 확인. 없으면 "추가 이미지 불필요" 한 줄. "바로 만들어"면 목록만 보이고 계속.
3. **계획** `work/PLAN.md`(3절: DNA·효과 표·소스 해부 표·동작 표·연기 표·전환 표·장면 표) → `plan-check.mjs P` 오류 0. 내레이션은 먼저 `work/narration.json`→`tts.mjs P`(시각 = 장면 길이).
4. **장면**(4절): `scene.mjs add P <id> <dom|canvas|three|stage> --dur 초 --title … --note …`→`scene/compositions/<id>.html`. DNA 는 `scene/index.html` 의 `window.DNA`·CSS 변수에만. 해부한 부품은 함수·리그로 만들어 장면끼리 공유한다(`scene/assets/` 의 공용 스크립트).
5. **애니메틱 검토 루프**: `board.mjs P`(스토리보드) + 장면마다 `board.mjs P --strip <id> --n 8` + `make.mjs P --draft`. 동작 표의 행마다 "그 동작이 보이는가"를 strip 으로 확인하고, 6절 채점표를 `work/review/round-N.md` 에 쓴다(항목마다 점수·근거 프레임 시각). 미달 항목만 고쳐 다시, **최대 3회**.
6. **⏸ 검토 요청**("바로 만들어"면 생략): 채점표(최신 round) · DNA 반영률 · 효과 표 · 시그니처→장면 · 동작 표 · 장면 표 · storyboard·strip·draft 경로 · 자신 없는 점→승인/장면 수정/스타일 조정.
7. **제작**: `work/sound.json`→`make.mjs P`(오디오→검사→게이트→계획 검사→채점 확인→렌더→검수→모션 검수). 렌더 후 qc.jpg·qc-motion.png·완성 영상 strip 으로 다시 채점(`round-N.md` 추가) → 미달이면 5로, **최대 2회**. 그래도 미달이면 항목·이유·선택지를 사용자에게 묻는다.
8. **납품**: `out/<폴더이름>.mp4`, 길이·해상도, 채점표(기준선이 있으면 나란히), 반영 DNA 한 줄, LUFS·문제 구간, 모션 검수 ✔/✗ 한 줄, 들어볼 것, 남은 약점. 수정 요청은 그 장면만 고쳐 make 재실행.

## 2.5 소스 해부·재구성
- **매체 일치가 기본**: 레퍼런스가 손그림·플랫 벡터·3D면 소스는 **그 매체로 다시 만든다**(사진을 보고 부품 함수로 다시 그림 — 부품 구성·색 배치·비율·실루엣을 부품 단위로 유지). 레퍼런스가 실사·사진 합성일 때만 사진 합성이 기본.
- **사진 그대로**는 예외 3가지만, 소스 해부 표 "예외 사유"에 적는다: `실사 매체`(레퍼런스가 실사) · `실물 공개`(의도된 실물 순간, 영상의 15% 이하) · `레이어 분리`(사진을 깊이·부위 레이어로 나눠 움직임을 줌). 단색 배경 사물 `cutout:true`(tol, 케이블 등에 갇힌 배경은 남으니 확인), 사람 `npx hyperframes remove-background source/x.jpg -o scene/assets/source/x.png`.
- **종류별 움직임 단위**(소스 해부 표 한 행 = 소스 한 장, 같은 대상의 여러 각도는 한 행에 묶어도 됨):

| 종류 | 움직임 단위 | 기본 움직임 |
|---|---|---|
| 관절 기계 | 링크·관절(회전 중심·가동 범위)·그리퍼·기어·케이블 | 관절 체인(부모 변환에 자식이 따라감)으로 집기·놓기, 기어 연동, 케이블 따라감 |
| 캐릭터 | 몸통·머리·눈·입·팔다리 | 걷기·점프·표정(`rig2d`). 몸통 1개+단순 눈·입→**코드 캐릭터** · 윤곽선·명암·질감 그림체→**파츠 시트** 요청(프롬프트 `modules/rig2d.md`). 파츠가 어긋나면 rig.json 회전 중심 수정, 안 되면 코드 캐릭터로 바꾸고 알린다 |
| 사람 | 부위 레이어 또는 일러스트화 | 미세 움직임·손짓·등장. 학생 얼굴은 브리프대로 |
| 제품 | 본체·버튼·화면·덮개·부품 | 버튼 눌림, 화면 켜짐·내용 변화, 분해·조립, 턴테이블 |
| 유연체 | 외곽선·덩어리 | 출렁임·말랑함·흩날림·조각나기 |
| 장소 | 전경·중경·배경·하늘·조명 | 시차 이동, 시간 변화, 작은 생명감(사람·빛) |
| 화면 | 컴포넌트(버튼·카드·목록·차트) | 커서·타이핑·스크롤·데이터 갱신 |
| 로고 | 벡터 경로 | 선 그리기·형태 변형·조각 조립 |

- **여러 각도 사진** = 같은 대상: 각도 전환 매치컷·턴테이블·시점 변화에 쓴다(카드로 나열 금지).
- **요청 이미지**: 소스·코드로 만들 수 없는 것 중 핵심만 필수(최대 5), 나머지 선택(최대 3). `work/assets.json`(형식 `assets.mjs` 맨 위)→`assets.mjs request P`→`work/ASSETS.md`: 파일 이름 영문 소문자_밑줄 · `why` 레퍼런스 구간 · `ref` 그 구간 프레임(`work/ref-*/shot_NN.jpg`) · `attach` 캐릭터·제품의 사용자 소스 · `size` 쓰일 크기 · 오려 쓸 것 `transparent: true`. 프롬프트(`prompt_en` 주, `prompt_ko` 설명): 대상+동작 / 구도·카메라 각도 / DNA HEX / 매체·질감·조명 / 비율 / `no text, no watermark, no logo` + 같은 스타일 문구. 레퍼런스 캐릭터·로고는 베끼지 말고 "in the style of the attached frame, original design". 안 온 것은 코드로 대체해 PLAN 11번에.
- 권리가 없으면 가상 대체물.

## 3. PLAN.md 틀 (예시 `<플러그인>/harness/PLAN-example.md` — 형식만, 색·스타일 제외)

레퍼런스가 좋은 이유: 1 … 5 (전부 시그니처로)
| # | 항목 | 레퍼런스 (근거) | 적용값 | 판정 |

규칙: **주 레퍼런스 1개**(보조는 지정 항목만) · 근거는 측정값(추정은 "(추정)") · 이유 없는 제외 금지 · **반영률 ≥ 8/10** · 시그니처 전부 사용 · 이야기·구성·캐릭터·음악은 안 가져옴(문법만) · **사용자 지정 색·배경 우선**(2·3번 '변형 — 사용자 지정').
- **소스 해부 표**: 종류 = 관절 기계/캐릭터/사람/제품/유연체/장소/화면/로고/기타, 재구성 = 다시 그리기/레이어 분리/3D/사진 그대로/미사용. 사진 그대로는 예외 사유(실사 매체·실물 공개·레이어 분리) 필수.
- **동작 표**: 브리프 "전달할 내용"의 동사 전부. 화면 동작은 **주체가 직접 하는 동작** — 라벨·자막·문구로만 처리하면 오류. 조작→반응→결과는 같은 시간축(반응 지연 0.1~0.2초).
- **연기 표**: 레퍼런스 연기 어휘를 우리 피사체에 매핑(사물도 의인화 정도는 브리프 톤대로). 레퍼런스에 주인공이 없으면 한 행 `해당 없음 | — | <사유> | —`.
- **전환 표**: 장면 경계마다 한 행. 이어주는 요소 = 앞 장면의 무엇이 다음 장면의 무엇이 되는가. 하드컷·페이드는 레퍼런스가 그럴 때만(근거 칸), 같은 방식 3회 초과 금지.
- 5번 ① 강도 → `window.DNA.motion`: `over`(오버슈트 비율)·`hold`(정지 초)는 analysis.md "① 기본기 강도" 측정값, `ant`(예비동작 비율)·`settle`(안착 초)·`squash`(최대 늘어남)는 판단(추정).
- 효과 표: id 는 `catalog.json` 것. ③ 근거 = `사용자 지정` + brief "## 효과 지정"에 그 id·`ko` 표현, ① 은 생략 가능. `lens.mblur` 행 = 렌더 약 4배(미리 알림). 사용 위치는 장면 id(`s3`) 또는 무대 비트(`st1 b2`).
- 질감은 측정값 그대로: 노이즈 σ≥1→`MH.grain`(움직이면 rate 12~24, 고정 0)·`MH.paper`, `MH.gradient`, `MH.vignette`. 화면 전체 비네트가 채움을 덮으면 채움 색이 갈라져 trans.fill 이 안 잡힌다→채움 아래 층에 두거나 채우는 동안 끈다.

## 4. 장면 엔진
**종류** — DNA를 가장 적은 코드로 재현하는 것:
- `dom` 타이포·레이아웃·카드·UI·키네틱 타이포. GSAP `fromTo` + `ease: "dna"`.
- `canvas` 그리드·선 드로잉·하프톤·픽셀·종이/그레인·데이터·**다시 그린 부품·관절 리그**·사진 합성→`modules/canvas.md`.
- `three` 여러 각도 사진 턴테이블·공간 속 카드·깊이 카메라·파티클→`modules/three.md`.
- `stage` 원테이크: 큰 월드·카메라·세트·배우를 큐시트 하나로(`MH.stage2d`), **`cam.onetake`·`trans.shared` 근거가 있을 때만**. 비트(`<id>-beats`) = 장면 표 한 행 = 스토리보드 한 칸. 25초 이하, 다른 종류와 혼용.
- 이름 붙은 효과(전환·타이틀·자막·차트·3D 배경)는 먼저 레지스트리: `npx hyperframes catalog --query "<영어>" --json`→`npx hyperframes add <이름> --json`(scene 폴더). 색·폰트는 DNA로.

**다시 그리기·리그**(소스 해부 표 → 코드) — 전부 t 의 순수 함수
- 부품 함수: 해부한 부품마다 `draw<부품>(ctx, 상태)`(빔·기어·버튼·화면·렌즈…). 손그림 매체면 `MH.boil(t,key,amp)` 로 꼭짓점을 떨고 해칭·이중선, 플랫이면 깨끗한 면.
- 관절 체인: `ctx.save→translate(관절)→rotate(각)→자식 그리기→restore`. 각도는 `MH.kf`/`MH.move` 키, 잡은 물체는 손끝 좌표를 따라간다(접촉 고정). 낙하·바운스는 `MH.phys.body`.
- 조작·반응 동기화: 입력(조이스틱·버튼) 키와 반응(관절) 키를 같은 배열에서 만들고 반응만 0.1~0.2초 늦춘다. 효과음 시각도 같은 배열에서.

**① 기본기**(게이트 없음, 손 키프레임 대신) — t 의 순수 함수, 생략한 강도는 `DNA.motion`(`MH.motion()`)
- `MH.move(t,t0,a,b,{dur,ant,over,settle})` 예비동작→이동→오버슈트→안착(숫자/배열)
- `MH.follow(t,fn,{lag,damp})` 늦게 따라감(fn 은 draw 밖에서 한 번)
- `MH.sim(t,step,init,update)` 결정적 시뮬(update 는 새 상태 반환) · `MH.phys.body({pos,vel,spin,g,bounce,floor}).at(t)`→{x,y,rot}
- `MH.gsapSpring(name,'snappy'|'smooth'|'heavy'|'playful'|{f,z})`→DOM 용 GSAP 이징 이름
- `MH.screenSize()`→[W,H](9:16, 1920×1080 가정 금지) · `MH.easeOf('dna'|E 이름|함수)`

**② 모듈은 효과 표에 켜진 것만 `modules/<이름>.md` 를 읽는다**(연기할 대상이 있으면 rig2d 도). 게이트가 찾는 변수 이름(`cam`·`trans`·`lens`·`fx`·`time`·`morph`)은 문서대로, 괄호 앞 공백 없이.
- rig.actor ①(캐릭터, 배우 `scene/assets/actors/<이름>.json`) `modules/rig2d.md` · cam.pan·push·rotate·shake·parallax `modules/camera2d.md` · trans.fill·zoomThrough·whip·match `modules/transitions.md`
- lens.dof·rack·smear·mblur `modules/lens2d.md` · fx.vhs·glitch, time.remap `modules/fx2d.md` · morph.shape·text `modules/morph.md` · cam.onetake·trans.shared(stage 종류) `modules/stage.md`

**HyperFrames 규칙**: `<template>` 안에 style·markup·script / 루트 id = 호스트 id = 타임라인 키 / `gsap.timeline({paused:true})`, 끝에 `window.__timelines["id"]=tl` / `from` 대신 `fromTo`, 절대 초 / `Date.now`·`Math.random`·타이머·`repeat:-1`·네트워크 금지(`MH.rng`) / 한 요소에 GSAP·CSS transform 동시 금지 / 경로 `assets/…` / 한글은 Pretendard `@font-face`(템플릿) / 비동기 로드 `window.__hf.buildReady[key]=promise`.
**장면 전환**: 전환 표대로. 다음 장면 `--start` 를 앞당겨 겹치고(z-index 위) 앞 장면 마지막 요소와 다음 장면 첫 요소를 맞춘다(형태 변형·`trans.match`·줌 통과). 전환 중 빈 화면 금지.

**MH 시간·이징**(모든 종류) — `t` = 장면 로컬 초, `MH.drive(tl, DUR, draw)` 의 draw(t) 는 순수 함수
- `tween(t,t0,d,ease)` 0→1 · `kf(t,[[t,v,ease],…])` · `springAt(t,t0,a,b,SPRING.snappy|smooth|heavy|playful)` · `seg(t,a,b)` · `quant(t,12)` 2s 느낌 · `breathe(t,amp,hz)` · `DNA.B(n)` n박→초
- `E.out/in/inOut/expoOut/back/smooth/snap` · `E.bez(x1,y1,x2,y2)` · `DNA.easeFn`

## 6. 채점표와 합격선
`work/review/round-N.md`(N = 1,2,…) 에 아래 표. 점수는 1~5(0.5 단위), 근거는 프레임 시각·strip 파일. 기준선(같은 입력으로 만든 다른 영상)이 있으면 `기준선` 열을 넣는다.
```markdown
채점표
| 항목 | 점수 | 기준선 | 근거 |
| 스타일 일치 | 5 | 4 | strip_s1 0.4–2.0s 손그림 선·종이 … |
```
| 항목 | 5점의 조건 |
|---|---|
| 스타일 일치 ★ | 매체·선·질감·색 비중이 레퍼런스와 같고, 좋은 이유 5가지가 전부 화면에 있다 |
| 소스 활용 ★ | 부품·색·비율을 알아볼 수 있고, **모든 소스 대상이 자기 부품으로 움직인다**. 여러 각도는 시점 전환으로 쓴다 |
| 내용 전달 ★ | 소리·글자를 끄고 봐도 동작 표의 동사가 전부 이해된다 |
| 움직임 ★ | 주요 동작마다 예비 동작·오버슈트·겹침 동작, 등속·급정지 없음, 화면에 항상 2차 움직임 |
| 카메라·전환 ★ | 경계 전부가 이어주는 요소로 연결, 레퍼런스 근거 안에서 전환 3종 이상, 같은 방식 3회 이하 |
| 캐릭터·연기 | 연기 표가 전부 보이고 피사체가 결과에 반응한다 |
| 타이포 | 레퍼런스와 같은 글자 비중, 매체에 맞는 서체, 중요한 것 ≥100px·글자 ≥28px(1080 기준), 유지 ≥ (글자수÷7+1.2)초 |
| 사운드 | 동작과 싱크, LUFS −14±1, 레퍼런스와 비슷한 효과음 밀도 |
| 기술 품질 | 오류·잘림·겹침·배경 제거 잔여물 0 |
| 효율 | 사람 개입은 처음 질문 + 검토 승인, 수정은 그 장면만 |

**합격선**: ★ 5개 = 5점, 나머지 ≥ 4.5, 기준선 열이 있으면 항목마다 기준선 + 1 이상(기준선 5면 5). `make.mjs` 는 최종 렌더 전에 최신 round 를 확인해 미달이면 멈춘다(`plan-check.mjs P --review`). 루프 상한(애니메틱 3회·제작 2회)을 넘기면 미달 항목·이유·선택지를 묻고, 사용자가 받아들이면 `make.mjs P --accept "<사유>"`.
**연출 최소 기준**: 3초 안에 훅 · 2~4초마다 새로운 것 + 홀드 한 번 · 끝은 처음의 변형 · 강조색은 한 의미 · 금지: 그라데이션 위 가운데 제목, 전부 페이드인, 의미 없는 파티클, 로고만 나오는 엔딩, **정지 사진 카드가 1.5초 넘게 화면을 차지**.
